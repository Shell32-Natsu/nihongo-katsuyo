# 活用練習帳

日语动词和形容词的变形练习网页。按 JLPT N5–N1 分级，要练哪些变形可以自己选，每道题都附带规则讲解和错因诊断。

这是一个纯静态网页：没有后端，不需要构建，也不调用 AI。所有讲解都由变形规则直接生成，打开就能用。

## 功能

- **词库**：667 个词（480 个动词、187 个形容词），可以按 JLPT 级别和词类筛选
- **变形**：动词 19 种（ます形、ない形、て形、た形、可能、被动、使役、使役被动、命令、ば形等），形容词 13 种（否定、过去、て形、副词形、敬体、〜そう、〜なる、修饰名词等），另有“判断类别”题
- **作答**：打字或四选一。打字时可以直接输入罗马字（`kaeranai` → かえらない），也可以用日文输入法写假名或汉字。选择题的错误选项来自常见错法，比如 帰ない、きれくない
- **讲解**：说明这个词属于哪一类、为什么，以及这次变形用的是哪条规则；遇到同音易混的词会提醒，比如 帰る（一类）和 変える（二类）
- **错因诊断**：能认出“按二类动词变了”“て形音便记混了”“写成了被动形”“把な形容词当成い形容词”等典型错误
- **复习**：各种变形的正确率按从低到高排列，答错的题进错题本，可以专门重练，答对一次就自动划掉
- 适配手机，支持深色模式。练习记录保存在浏览器的 localStorage 里，换浏览器或设备不会同步

## 使用

直接用浏览器打开 `index.html` 即可。也可以起一个本地服务器：

```sh
python3 -m http.server
# 然后访问 http://localhost:8000
```

### 发布到 GitHub Pages

在仓库的 **Settings → Pages** 里，Source 选 **Deploy from a branch**，Branch 选 `main` 和 `/ (root)`，保存。几分钟后就能在 `https://shell32-natsu.github.io/nihongo-katsuyo/` 打开。

## 目录结构

```
index.html          页面结构
style.css           样式（浅色、深色两套配色）
js/data.js          词库
js/engine.js        变形引擎：变形规则、判定、讲解、错因诊断、选择题干扰项
js/app.js           界面：设置、出题、罗马字输入、统计和错题本
test/               引擎测试
```

## 添加或修改单词

词库在 `js/data.js`，每行一个词，用 `|` 分隔：

```
写法|读音|中文|JLPT级别|词类|标记（可选）
帰る|かえる|回去|5|1
開く|あく|开（自动）|5|1|nv
```

词类：

| 代码 | 含义 |
| --- | --- |
| `1` | 一类动词（五段） |
| `2` | 二类动词（一段） |
| `s` | 三类动词，サ变（する、勉強する） |
| `k` | 三类动词，カ变（来る、持って来る） |
| `i` | い形容词 |
| `n` | な形容词 |

标记（多个用 `;` 分隔）：

| 标记 | 作用 |
| --- | --- |
| `nv` | 非意志动词，不出可能、被动、使役、使役被动、意志、ましょう、命令、禁止、たい这几种题 |
| `x=pot,pass` | 排除指定的变形（变形代码见 `js/engine.js` 里的 `FORMS`） |
| `ok=caus` | 在 `nv` 的基础上重新允许某些变形 |
| `imp=くれ` | 指定特殊的命令形 |
| `aru` | ある 的否定是 ない |
| `iku` | 行く 的て形是 行って |
| `ii` | いい 系形容词变形时换成 よ（よくない、よかった） |

改完词库后跑一遍测试，确认每个词都能正常出题。

## 测试

需要 Node.js 18 或更新版本：

```sh
node --test
```

测试覆盖常见变形和特例的判定、典型错误的诊断，并检查词库里每个词的每种变形都有答案、讲解，以及 4 个不重复且只有一个正确的选项。
